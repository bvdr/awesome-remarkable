# Awesome reMarkable [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of products, services, and open-source projects for the [reMarkable](https://remarkable.com) paper tablet.

reMarkable makes distraction-free e-paper tablets for writing, reading, and reviewing documents. This list collects the official hardware, the third-party apps and services that extend it, and the open-source community that hacks, syncs, and builds on top of it.

Prices are in USD and current as of June 2026. They change often and vary by region, so always confirm on the official store before buying.

## Open Source

The community ecosystem around reMarkable. The reference community list is [reHackable/awesome-reMarkable](https://github.com/reHackable/awesome-reMarkable), worth a look for historical projects.

**A note on device generations:** the classic hacking stack ([Toltec](https://github.com/toltec-dev/toltec), ddvk hacks) targets the reMarkable 1 and 2. For the Paper Pro and newer firmware 3.x devices, the modern stack is built on [XOVI](https://github.com/asivery/xovi). Tools that parse the older `.lines` format do not read the v6 `.rm` format used since late 2022; use rmscene, rmc, or rmconvert for current files.

### Device Hacking & Package Managers

| Project | Description |
|---------|-------------|
| [toltec-dev/toltec](https://github.com/toltec-dev/toltec) | Community package repository (opkg/Entware) for reMarkable 1 and 2 apps. |
| [asivery/xovi](https://github.com/asivery/xovi) | Universal `LD_PRELOAD` extension framework, the modern base for hacks across rM1/2 and Paper Pro. |
| [asivery/rm-xovi-extensions](https://github.com/asivery/rm-xovi-extensions) | Monorepo of XOVI extensions (resource rebuilder, file manager, and more). |
| [asivery/rm-appload](https://github.com/asivery/rm-appload) | XOVI extension that lets third-party apps run in windowed or fullscreen mode. |
| [asivery/rm-hacks-qmd](https://github.com/asivery/rm-hacks-qmd) | XOVI-based feature tweaks covering rM1/2, Paper Pro, and Pro Move. |
| [ddvk/remarkable-hacks](https://github.com/ddvk/remarkable-hacks) | Classic binary-patching hacks for extra features. Historically important, largely superseded by XOVI. |
| [Evidlo/remarkable_entware](https://github.com/Evidlo/remarkable_entware) | Entware package manager installer for reMarkable. |
| [hmenzagh/rmpp-entware](https://github.com/hmenzagh/rmpp-entware) | Entware package manager for the Paper Pro. |
